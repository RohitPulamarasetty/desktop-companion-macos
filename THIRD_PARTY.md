# Third-party assets

## Pixel Dogs by Benvictus

All character artwork in `Characters/` is derived from **Pixel Dogs** by
**Benvictus** — https://benvictus.itch.io/pixel-dogs.

The author stated on the itch.io page that the sprites may be used
commercially and asked to be credited. There is no formal SPDX license, so
this is the author's own stated permission, not an open license. The sprite
strips in this repository are re-sequenced frames from the original sheets
(no pixels redrawn); the original download is not redistributed here.

The artwork is **not** covered by this project's MIT license and is not owned
by this project. If you want to redistribute it in another product, check
with the author first.
